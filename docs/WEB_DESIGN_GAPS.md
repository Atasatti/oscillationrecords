# Web design — what you may have forgotten

## 1. TL;DR — highest-leverage next steps

- **Give every public page exactly one `<h1>`** and fix the `<h1>→<h3>` heading skip (homepage hero, /artists, /releases, /press all currently lack an h1).
- **Fill the `[bracket]` placeholders and `[DATE]` on the live Privacy & Terms pages** — bracketed text renders verbatim to the public and reads as unfinished/untrustworthy.
- **Add `export const viewport` (`viewportFit:'cover'`, `themeColor:'#000000'`, `colorScheme:'dark'`) + safe-area padding** so the fixed MusicPlayer/Navbar/mobile-menu don't clip on notched phones.
- **Fix the /contact layout** — the form + collage never stack on mobile, squeezing the demo-submission form to ~200px; this is a primary conversion page.
- **Integrate a transactional email provider (Resend + `lib/email.ts`)** — no mailer exists, so contact leads, newsletter, and competition entries all go unacknowledged and unnotified.
- **Add a skip-to-content link + `<main id>`** and a global `:focus-visible` baseline — cheap WCAG bypass-block and focus-ring fixes.
- **Pick and enforce ONE canonical host (www vs apex)** — `lib/seo.ts` says apex, `lib/indexnow.ts` says www, and no redirect exists (duplicate-content risk).
- **Make transient DB failures render a retryable 500, not a cached 404/empty grid** — detail and list getters `catch { return null/[] }`, so a DB blip is indexed as "gone" or "empty" for up to 60s (ISR).

## 3. Quick wins (do these first)

Low-effort, high/medium-impact — mostly one-file or a few lines:

- **`viewport` export** (`app/layout.tsx`) — unlocks safe-area, theme-color, and color-scheme in one shot.
- **Fill legal placeholders** — `[DATE]`, jurisdiction, entity/address in `privacy` & `terms`; company details already public in the Footer.
- **Skip-to-content link + `<main id>`** — ~5 lines, WCAG bypass-block.
- **Global `:focus-visible` rule** in `globals.css` — one CSS rule covers every element authors forgot.
- **`priority` on the two detail-page hero images** — direct LCP win.
- **Wire existing `BLUR_DATA_URL` into card `<Image>`s** — zero new assets, kills pop-in on the busiest surfaces.
- **Canonical-host 308 redirect** — removes a real duplicate-content risk; align seo/indexnow envs.
- **Contact-form admin notification + share buttons** — highest cheap conversion/virality wins (share needs no new deps; notify needs `lib/email.ts`).
- **`app/manifest.ts` + theme-color** — installability and no white chrome bar.
- **Contact honeypot field** — zero-friction spam deterrent.
- **`app/not-found.tsx` (root)** — guarantees a branded, correct-status 404 everywhere.
- **`security.txt` + accessibility statement pages** — low effort, both signal professionalism given the a11y/security work already done.

## 4. Already strong (a fair baseline)

This site is well ahead of most indie-label builds. Verified strengths worth keeping in view:

- **SEO foundation:** dynamic `robots.ts`/`sitemap.ts` (with `image:image`), rich JSON-LD (Organization, MusicGroup, MusicAlbum, BreadcrumbList, FAQ, WebSite, BlogPosting), per-page metadata (title/desc/OG/Twitter), IndexNow auto-submit, `llms.txt`, and GSC verification.
- **Analytics & privacy done right:** GA4 + Clarity both consent-gated and excluded from /admin, first-party beacons, a cookie-consent banner, plus GDPR data export and account deletion.
- **Error handling in place:** `global-error.tsx`, `(main)/error.tsx`, `(main)/not-found.tsx`, server `instrumentation.ts`, a client error logger, and an admin errors page (the gaps above are refinements, not a missing baseline).
- **Security posture:** strict-nonce CSP for /admin (relaxed for public), security response headers, rate limiting, roles/permissions, and an audit log.
- **Performance fundamentals:** `next/image` with a `remotePatterns` allowlist, `next/font`, and ISR revalidation.
- **Brand & motion care:** a `BRAND.md` design system, custom fonts, film-grain overlay, a music player, and `prefers-reduced-motion` support (correctly applied in the card components — the fix is just extending it to `ScrollReveal3D`/`Navbar`).
- **Forms:** working public contact form and newsletter signup already shipped.

The recurring theme in the gaps is **fail-soft data paths that hide outages** (404/empty-on-DB-error), **mobile/notch polish** (viewport + safe-area), **the missing email layer**, and **a11y finish work** (h1s, skip link, focus-visible) — none require a redesign, and the highest-leverage fixes are mostly low-effort.
